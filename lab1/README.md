# Бот-планировщик: Telegram → TickTick

Вы пишете боту задачу обычным текстом, LLM понимает, что нужно сделать, выбирает подходящий список (проект) и бот выполняет действие через официальный [TickTick CLI](https://help.ticktick.com/articles/7465251130025443328).

## Что умеет

| Область | Возможности |
|---|---|
| Задачи | создать (описание, теги, срок, приоритет, напоминание), изменить, перенести в другой проект, завершить |
| Поиск | по тексту, тегам, приоритету, статусу |
| Проекты | создать, посмотреть, переименовать / сменить цвет, удалить (с подтверждением кнопкой) |
| Привычки | создать, посмотреть, изменить (удаления нет) |

Примеры сообщений:

- `Завтра в 10 созвон с клиентом, высокий приоритет, напомни за 30 минут`
- `Купить молоко #дом`
- `Поставь ей средний приоритет` (бот помнит последнюю задачу)
- `Перенеси задачу про отчёт в проект Работа`
- `Найди активные задачи с тегом work и высоким приоритетом`
- `Создай проект Отпуск` / `Переименуй проект Отпуск в Путешествия`
- `Создай привычку пить воду, цель 8 стаканов`

Ответ бота выглядит так:

```
✅ Задача «Созвон с клиентом» создана в проекте «Работа».
📅 Срок: 10.10.2026 10:00
⏰ Напоминание: за 30 мин до срока
🔥 Приоритет: высокий
```

## Установка

### 1. TickTick CLI

Нужен Node.js. Затем:

```bash
npm install -g @ticktick/ticktick-cli
ticktick auth login        # откроется браузер, войдите в TickTick
ticktick auth status       # проверка
ticktick project list --json
```

Если последняя команда показала ваши списки, CLI настроен.

### 2. Telegram-бот

1. Откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`.
2. Название: например `Planner Bot`. Username по заданию: `itmoftmi_ИНИЦИАЛЫ_bot`.
3. Сохраните токен.
4. Узнайте свой числовой ID у [@userinfobot](https://t.me/userinfobot).

### 3. LLM

Подойдёт любой сервис с OpenAI-совместимым API (OpenAI, OpenRouter и другие). Нужны ключ, при необходимости адрес (`LLM_BASE_URL`) и название модели.

### 4. Запуск бота

Нужен Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env               # Windows: copy .env.example .env
# заполните .env: токен бота, ALLOWED_USER_ID, ключ LLM

python bot.py
```

Откройте бота в Telegram, отправьте `/start` и напишите первую задачу.

## Важно знать

- **Запускайте бота на той же машине, где выполнили `ticktick auth login`.** Токен CLI хранится локально, и бот использует именно его. На сервере без браузера авторизацию придётся делать отдельно.
- **Обязательно задайте `ALLOWED_USER_ID`.** Иначе любой, кто найдёт бота, сможет менять ваш TickTick.
- **Хранение данных.** Бот ведёт маленький файл `data.json`: кэш списка проектов (5 минут) и последнюю задачу, чтобы работали фразы вроде «поставь ей высокий приоритет». Задачи хранятся только в TickTick.
- **Удаление проекта** всегда требует подтверждения кнопкой. Удаления задач и привычек нет намеренно.
- Если LLM не смогла выбрать проект, задача уходит в `DEFAULT_PROJECT_ID` (если задан), иначе бот попросит уточнить.

## Если что-то работает не так

Код написан по документации CLI, но форматы ответов `--json` и параметры могут отличаться от ожидаемых. Проверьте по порядку:

1. `ticktick task create --help` — названия флагов (`--content`, `--tags`, `--priority`, `--due-date`, `--reminders`).
2. `ticktick project list --json` — у проектов должны быть поля `id` и `name`.
3. Формат напоминаний описан в документации CLI (раздел «reminders format»). Бот использует `TRIGGER:-PT30M` (за 30 минут) и `TRIGGER:PT0S` (в момент срока). Если у вас иначе, поправьте функцию `reminder_trigger` в `bot.py`.
4. Подробности ошибок смотрите в консоли, где запущен бот.

## Структура проекта

```
bot.py            код бота (все функции прокомментированы)
requirements.txt  зависимости
.env.example      пример конфигурации
data.json         создаётся автоматически
```

## Стек

- `python-telegram-bot` — работа с Telegram.
- `openai` — клиент для LLM (работает с любым OpenAI-совместимым API).
- `python-dotenv` — чтение настроек из `.env`.
- TickTick CLI — единственный способ общения с TickTick, бот ничего не делает в обход него.
