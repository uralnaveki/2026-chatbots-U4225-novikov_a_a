# VibeCoding: Telegram-бот-планировщик для TickTick

Бот принимает задачу обычным текстом в Telegram и сам кладёт её в нужный список TickTick: подбирает проект, срок, приоритет, теги и напоминание. Проект создан методом vibe coding: весь код написан LLM по текстовому промпту, без ручного программирования.

- **Лабораторная 1:** бот-ассистент для задач (Telegram + LLM + TickTick CLI).
- **Лабораторная 2:** подключение к данным. Добавлены источники данных: SQLite (история и статистика), публичный API погоды Open-Meteo, CSV-файлы (выгрузка и загрузка задач) и RSS-ленты новостей о научных стартапах с переводом через LLM.

## Как это работает

```
Вы в Telegram → бот → LLM (разбор фразы в JSON-команду) → TickTick CLI → ваш список задач
                  │                                                         │
                  ├── SQLite (bot.db): история действий и статистика        │
                  ├── Open-Meteo API: погода для плана на сегодня           │
                  ├── CSV-файлы: выгрузка задач и загрузка из файла         │
                  ├── RSS-ленты: новости о стартапах + перевод через LLM    │
                  └────────────── ответ: что именно сделано ←───────────────┘
```

1. Вы пишете: «Завтра в 10 созвон с клиентом, высокий приоритет, напомни за 30 минут».
2. LLM получает фразу, текущее время и список ваших проектов и возвращает команду (действие и параметры).
3. Бот выполняет её через официальный [TickTick CLI](https://help.ticktick.com/articles/7465251130025443328), записывает действие в SQLite и подтверждает результат.

Сами задачи бот у себя не хранит: источник данных о задачах остаётся в TickTick. В `data.json` лежит только кэш списка проектов и последняя задача (чтобы работали фразы вроде «поставь ей средний приоритет»).

## Возможности

| Область | Что умеет |
|---|---|
| Задачи | создать (описание, теги, срок, приоритет, напоминание), изменить, перенести в другой проект, завершить |
| Поиск | по тексту, тегам, приоритету, статусу |
| Проекты | создать, посмотреть, переименовать, сменить цвет, удалить (только с подтверждением кнопкой) |
| Привычки | создать, посмотреть, изменить (удаления нет) |
| История и статистика (SQLite) | что бот делал за период, поиск по истории, сводка по проектам |
| План на сегодня и погода (Open-Meteo) | задачи на сегодня, просроченные и погода одним сообщением |
| CSV | выгрузка задач в файл и создание задач из присланного файла |
| Новости (RSS) | свежие новости о научных и технологических стартапах на русском, утренний дайджест по расписанию |

Примеры фраз:

- `Купить молоко завтра в 18:00 #дом`
- `Поставь ей средний приоритет и перенеси в проект Учёба`
- `Найди активные задачи с тегом дом`
- `Что я делал за неделю?`, `Что я делал по проекту Учёба?`
- `План на сегодня`, `Какая погода в Казани?`
- `Выгрузи задачи в файл`
- `Что нового у научных стартапов?`
- `Создай привычку пить воду, цель 8 стаканов`

## Команды

| Команда | Что делает |
|---|---|
| `/start`, `/help` | справка |
| `/projects` | список проектов |
| `/habits` | список привычек |
| `/today [город]` | план на сегодня: погода, задачи со сроком на сегодня, просроченные |
| `/weather [город]` | только погода (по умолчанию город из `WEATHER_CITY`) |
| `/history [дни] [слово]` | история действий за период (по умолчанию 7 дней); слово ищет по названию и проекту |
| `/stats [дни]` | статистика: сколько задач создано, изменено и завершено, по проектам |
| `/export [done]` | выгрузка активных (или выполненных) задач в CSV-файл |
| `/news [N]` | N свежих новостей о научных стартапах (по умолчанию 5), переведённых на русский |
| `/news_on [ЧЧ:ММ]` | включить утренний дайджест (по умолчанию 08:00 по `TIMEZONE`) |
| `/news_off` | выключить дайджест |
| CSV-файл в чат | создаёт задачи из файла |

## Источники данных (лабораторная 2)

Код источников вынесен в файл `integrations.py`, а `bot.py` подключает их к командам и к разбору фраз.

### 1. SQLite: история и статистика

Файл `bot.db` создаётся автоматически. Каждое действие бота (создание, изменение, завершение задачи, проекты, привычки, выгрузка) записывается в таблицу `actions`:

| Поле | Что хранит |
|---|---|
| `user_id` | Telegram ID пользователя |
| `created_at` | время действия (UTC) |
| `action` | вид действия: `task_create`, `task_update`, `task_complete`, … |
| `title` | название задачи, проекта или привычки |
| `project` | проект, в котором это произошло |
| `details` | что именно изменили |
| `source_text` | исходная фраза пользователя |

Если базу открыть не удалось, бот продолжает работать, а история и статистика отключаются с понятным сообщением.

### 2. Публичный API: Open-Meteo

[Open-Meteo](https://open-meteo.com/) не требует ключа и бесплатен. Бот находит координаты города через Geocoding API, затем запрашивает текущую погоду и прогноз на сегодня. Ответы кэшируются на 10 минут. Если сервис недоступен, `/today` всё равно покажет задачи, а `/weather` сообщит о проблеме.

### 3. CSV-файлы

**Выгрузка.** `/export` присылает файл `tasks_ГГГГ-ММ-ДД.csv` (разделитель `;`, кодировка UTF-8 с BOM, открывается в Excel без «кракозябр»).

**Загрузка.** Пришлите боту CSV-файл, и он создаст задачи. Пример файла: `tasks_example.csv`.

| Колонка | Обязательна | Формат |
|---|---|---|
| `title` (или `название`) | да | текст |
| `project` (или `проект`) | нет | название проекта из TickTick; без него задача уйдёт в `DEFAULT_PROJECT_ID` |
| `due` (или `срок`) | нет | `2026-10-15 18:00`, `15.10.2026 18:00`, `2026-10-15` (без времени ставится 09:00) |
| `priority` (или `приоритет`) | нет | `нет`, `низкий`, `средний`, `высокий` (или 0, 1, 3, 5) |
| `tags` (или `теги`) | нет | через `;` или `,` |
| `description` (или `описание`) | нет | текст |

Разделитель `;` или `,` определяется автоматически, кодировки UTF-8 и Windows-1251 (русский Excel) поддерживаются. За один раз обрабатывается до 50 строк, размер файла до 200 КБ. Строки с ошибками пропускаются, а бот перечисляет их с номерами.

### 4. RSS: новости о научных стартапах

Источники (открытые RSS-ленты на английском):

| Источник | Лента |
|---|---|
| TechCrunch Startups | `techcrunch.com/category/startups/feed/` (берётся целиком) |
| MIT Technology Review | `technologyreview.com/feed/` |
| Singularity Hub | `singularityhub.com/feed/` |
| ScienceDaily Technology | `sciencedaily.com/rss/top/technology.xml` |

Из общих лент (все, кроме TechCrunch) оставляются записи с ключевыми словами о стартапах и науке (startup, funding, biotech, quantum, robot и т. д.; список `NEWS_KEYWORDS` в `integrations.py`). Дальше бот убирает повторы, отбрасывает записи старше 3 дней, берёт не больше двух новостей из одного источника и просит LLM перевести заголовки и пересказать суть одним предложением по-русски. В сообщении остаются заголовок, пересказ, название источника и ссылка на оригинал: полные тексты статей бот не копирует.

**Утренний дайджест.** `/news_on 08:00` сохраняет подписку в SQLite (таблица `news_subs`) и ставит ежедневную задачу в планировщик. Уже присланные ссылки запоминаются (`news_sent`), поэтому новости не повторяются. После перезапуска бота подписка восстанавливается сама. Нужен пакет `python-telegram-bot[job-queue]` (указан в `requirements.txt`); бот должен быть запущен в нужное время.

Если часть лент недоступна, берутся остальные; если LLM не смогла перевести, приходят оригинальные заголовки с пометкой.

## Что понадобится

- Python 3.10 или новее
- Node.js (LTS) — для TickTick CLI
- Аккаунт TickTick
- Бот в Telegram (токен от [@BotFather](https://t.me/BotFather))
- Ключ любого сервиса с OpenAI-совместимым API (например, [OpenRouter](https://openrouter.ai))

Ключ для Open-Meteo не нужен.

## Установка

### 1. TickTick CLI

```bash
npm install -g @ticktick/ticktick-cli
ticktick auth login          # откроется браузер для входа
ticktick project list --json # проверка: должны показаться ваши проекты
```

### 2. Бот

Создайте виртуальное окружение и активируйте его:

```bash
python -m venv .venv
```

- Windows: `.venv\Scripts\activate`
- macOS / Linux: `source .venv/bin/activate`

После активации в начале строки появится `(.venv)`. Установите зависимости:

```bash
pip install -r requirements.txt
```

### 3. Настройка `.env`

Скопируйте пример и заполните значения:

- Windows: `copy .env.example .env`
- macOS / Linux: `cp .env.example .env`

| Переменная | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| `ALLOWED_USER_ID` | ваш числовой ID (узнать у [@userinfobot](https://t.me/userinfobot)); бот отвечает только вам |
| `LLM_API_KEY` | ключ сервиса LLM |
| `LLM_BASE_URL` | адрес API; для OpenRouter `https://openrouter.ai/api/v1`, пусто = OpenAI |
| `LLM_MODEL` | название модели, например `openai/gpt-4o-mini` |
| `TICKTICK_BIN` | команда запуска CLI (если не находится, укажите полный путь) |
| `DEFAULT_PROJECT_ID` | необязательно: проект по умолчанию |
| `TIMEZONE` | часовой пояс, по умолчанию `Europe/Moscow` |
| `WEATHER_CITY` | город для `/today` и `/weather`, по умолчанию `Москва` |
| `DB_FILE` | файл SQLite, по умолчанию `bot.db` |
| `NEWS_COUNT` | сколько новостей в дайджесте (1–10), по умолчанию 5 |

Значения пишутся без кавычек и пробелов вокруг `=`.

### 4. Запуск

```bash
python bot.py
```

В консоли появится строка «Бот запущен». Откройте бота в Telegram и отправьте `/start`.

Запускайте бота на той же машине и в том же окне терминала, где работает команда `ticktick`: вход в TickTick сохраняется локально.

## Структура проекта

```
bot.py              бот: Telegram, разбор фраз через LLM, действия, команды
integrations.py     источники данных: SQLite, Open-Meteo, CSV, RSS
requirements.txt    зависимости
.env.example        пример конфигурации
tasks_example.csv   пример файла для загрузки задач
.gitignore          исключает .env, .venv, data.json, bot.db
data.json           создаётся автоматически (кэш проектов, последняя задача)
bot.db              создаётся автоматически (история действий, подписки на новости)
```

## Безопасность

- Файл `.env` содержит секреты, не добавляйте его в репозиторий (он указан в `.gitignore`).
- Обязательно задайте `ALLOWED_USER_ID`, иначе бот будет отвечать всем.
- Если ключ или токен попал в публичный доступ, отзовите его: ключ на странице OpenRouter, токен бота командой `/revoke` у @BotFather.
- Бот не удаляет задачи и привычки, а удаление проекта требует подтверждения.
- Запросы к базе параметризованы, текст пользователя не может изменить SQL. Из CSV в TickTick уходит только текст полей, а опасные символы командной строки Windows заменяются.

## Обработка ошибок

| Ситуация | Что делает бот |
|---|---|
| Нет CLI, нет входа в TickTick, таймаут CLI | сообщение «Ошибка TickTick CLI» с подсказкой |
| Сервис погоды недоступен или не ответил за 10 секунд | `/weather` сообщает о сбое, `/today` показывает задачи без погоды |
| Неизвестный город | «Не нашёл город», подсказка проверить название |
| Нет истории за период | «Ничего не найдено» |
| База SQLite не открылась | история и статистика отключены, остальное работает |
| CSV: пустой файл, нет колонки `title`, неверная кодировка | понятное сообщение, задачи не создаются |
| CSV: плохая дата, приоритет, неизвестный проект | строка пропускается, в итоге перечислены номера строк и причины |
| Слишком большой файл или не CSV | сообщение с требованиями к файлу |
| Лента новостей не ответила или вернула не RSS | берутся остальные ленты; если не ответила ни одна, сообщение о сбое |
| LLM не смогла перевести новости | дайджест уходит с оригинальными заголовками |
| Неверное время в `/news_on` | подсказка с форматом ЧЧ:ММ |
| Нет планировщика (`job-queue`) | подсказка, какой пакет поставить |

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| `source` не является командой (Windows) | используйте `.venv\Scripts\activate` |
| «команда ticktick не найдена» | установите CLI и перезапустите терминал; запускайте бота из окна, где работает `ticktick --help`; при необходимости укажите путь в `TICKTICK_BIN` |
| 401 «Missing Authentication header» | в `.env` не указан или неверно указан `LLM_API_KEY`; после правки перезапустите бота |
| «LLM вернула некорректный JSON» | бесплатные модели иногда отвечают не чистым JSON; повторите запрос или смените модель |
| `/today` пишет «Погода недоступна» | нет интернета или сервис не ответил; повторите позже |
| CSV: «нет проекта» | название проекта в файле должно совпадать с названием в TickTick (регистр не важен) |
| `/news_on` просит установить планировщик | `pip install "python-telegram-bot[job-queue]"` и перезапуск |
| Дайджест не пришёл утром | бот должен работать в это время; проверьте время через `/news_on ЧЧ:ММ` и часовой пояс `TIMEZONE` |
| Бот молчит | проверьте `ALLOWED_USER_ID` и ошибки в консоли |

При запуске бот печатает строку с настройками LLM (адрес, модель, длину и начало ключа), по ней легко найти ошибку в `.env`.
