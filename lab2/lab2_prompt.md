# Промпт для лабораторной работы 2

Промпт составлен по шаблону из задания («Улучши моего Telegram-бота, добавив работу с [тип данных]»). Его можно вставить в раздел отчёта «Исходный промпт» и «Финальный промпт».

```text
Улучши моего Telegram-бота, добавив работу с данными: SQLite, публичным API, CSV-файлами и RSS-лентами новостей.

Текущий функционал бота:
Telegram-бот-планировщик на Python (python-telegram-bot). Пользователь пишет задачу обычным текстом, LLM (через OpenAI-совместимый API) превращает фразу в JSON-команду, а бот выполняет её через официальный TickTick CLI. Бот умеет: создавать, менять, переносить в другой проект и завершать задачи (описание, теги, срок, приоритет, напоминание), искать и фильтровать задачи, создавать, переименовывать и удалять проекты (удаление с подтверждением кнопкой), создавать, смотреть и менять привычки. Ограничения: бот отвечает только владельцу (ALLOWED_USER_ID), задачи и привычки не удаляет, все ошибки превращает в понятные сообщения.

Новый функционал:
- SQLite (файл bot.db): записывать каждое действие бота (создание, изменение, завершение задач, проекты, привычки, выгрузка) в таблицу actions: user_id, время (UTC), вид действия, название, проект, детали, исходная фраза пользователя. Команда /history [дни] [слово] показывает действия за период (по умолчанию 7 дней) с поиском по слову (в том числе по кириллице без учёта регистра). Команда /stats [дни] показывает, сколько задач создано, изменено и завершено, и разбивку по проектам.
- Публичный API Open-Meteo (без ключа): команда /weather [город] показывает текущую погоду и прогноз на сегодня, город находится через Geocoding API. Команда /today [город] присылает план на сегодня: погода, задачи со сроком на сегодня и просроченные (из TickTick). Ответы API кэшировать на 10 минут. Если API недоступен, /today всё равно показывает задачи.
- CSV: команда /export [done] отправляет файл с активными (или выполненными) задачами: колонки title, project, due, priority, tags, description, status, разделитель ";", кодировка UTF-8 с BOM. Если пользователь присылает CSV-файл, бот создаёт из него задачи в TickTick. Поддержать разделители ";" и ",", кодировки UTF-8 и Windows-1251, русские и английские названия колонок, форматы дат 2026-10-15 18:00, 15.10.2026 18:00 и 2026-10-15 (без времени - 09:00), приоритеты словами и цифрами. До 50 строк и 200 КБ за раз. Некорректные строки пропускать и перечислять с номерами.
- RSS-новости: команда /news [N] показывает свежие новости о научных и технологических стартапах из английских RSS-лент (TechCrunch Startups, MIT Technology Review, Singularity Hub, ScienceDaily Technology). Из общих лент оставлять записи с ключевыми словами о стартапах, убирать повторы и записи старше 3 дней, брать не больше двух новостей из одного источника. LLM переводит заголовки на русский и пересказывает суть одним предложением; в сообщении только заголовок, пересказ, источник и ссылка (полные тексты не копировать). Команды /news_on [ЧЧ:ММ] и /news_off включают и выключают утренний дайджест (по умолчанию 08:00): подписка хранится в SQLite (news_subs), отправленные ссылки тоже (news_sent), задача ставится через JobQueue и восстанавливается после перезапуска.
- Фразы на естественном языке должны работать так же, как команды: «Что я делал за неделю?», «Статистика за месяц», «План на сегодня», «Какая погода в Казани?», «Выгрузи задачи в файл», «Что нового у научных стартапов?». Для этого расширить системный промпт LLM новыми действиями (history, stats, today, weather, export, news).

Данные:
- SQLite: таблица actions (id, user_id, created_at, action, title, project, details, source_text).
- Open-Meteo: https://open-meteo.com/en/docs (прогноз) и https://open-meteo.com/en/docs/geocoding-api (поиск города).
- RSS: https://techcrunch.com/category/startups/feed/, https://www.technologyreview.com/feed/, https://singularityhub.com/feed/, https://www.sciencedaily.com/rss/top/technology.xml
- CSV: пример файла tasks_example.csv с колонками title;project;due;priority;tags;description.

Требования:
- Код должен быть простым и понятным
- Добавить обработку ошибок: недоступный API и таймаут, недоступная RSS-лента, сбой перевода LLM, неверное время дайджеста, неизвестный город, пустая история, недоступная база, пустой или некорректный CSV, неверная дата или приоритет в строке, неизвестный проект
- Хорошие комментарии в коде
- Сохранить существующий функционал
- Новый код источников данных вынести в отдельный файл integrations.py

Создай:

1. Обновленный bot.py
2. Файл integrations.py и файл с данными tasks_example.csv
3. Обновленный README.md, .env.example и requirements.txt
```
